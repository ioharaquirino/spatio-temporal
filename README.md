# spatio-temporal
R scripts for the spatio-temporal analysis of the Scottish Atlantic mackerel fishery (1999–2023)

This repository contains the main R scripts supporting the analyses presented in the manuscript:

“Assessing spatio-temporal patterns and trends in the Scottish mackerel trawl fishery using a novel industry dataset”

The study investigates spatio-temporal patterns in the activity of the Scottish pelagic fishing fleet targeting Atlantic mackerel (Scomber scombrus) between 1999 and 2023. The analyses integrate high-resolution industry chart plotter data with Vessel Monitoring System (VMS) and self-sampling data.

The scripts provided here cover the main data processing, spatial analyses, statistical analyses, and visualisations used in the study.

Analyses were conducted in R using RStudio. Required packages are identified within the individual scripts.
